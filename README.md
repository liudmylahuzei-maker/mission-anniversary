# Mission Anniversary v2.0 ❤️

A static anniversary mini-game designed to be hosted for free with GitHub Pages.

## Personalization

Open `script.js` and edit the `CONFIG` object plus the `memories` object.

Replace the placeholder images in `assets/` with your real photos. Keep the same filenames (`first-date.jpg`, `first-trip.jpg`, `favorite-memory.jpg`, `future-plans.jpg`) or update the paths in `script.js`.

The authentication password is currently `25072021`.

## Run locally

Open `index.html` in a browser. No Node.js, build step, framework, database, or backend is required.

## Publish free on GitHub Pages

1. Create a public GitHub repository, for example `mission-anniversary`.
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will publish the project at `https://YOUR-USERNAME.github.io/mission-anniversary/`.

You can also use a repository named `YOUR-USERNAME.github.io` for a root GitHub Pages site.
